อินเทอร์เน็ตทำงานอย่างไร?

สรุป
อินเทอร์เน็ต เป็นหัวใจสำคัญของเว็บ เป็นโครงสร้างพื้นฐานทางเทคนิคที่ทำให้เว็บเป็นไปได้ ในระดับพื้นฐานที่สุด 
อินเทอร์เน็ตคือเครือข่ายคอมพิวเตอร์ขนาดใหญ่ที่สื่อสารกันทั้งหมด

เครือข่ายอย่างง่าย
เมื่อคอมพิวเตอร์สองเครื่องต้องการสื่อสารกัน คุณต้องเชื่อมต่อคอมพิวเตอร์ทั้งสองเข้าด้วยกัน ไม่ว่าจะเป็นการเชื่อมต่อทางกายภาพ 
(โดยปกติจะใช้สายอีเธอร์เน็ต ) หรือการเชื่อมต่อแบบไร้สาย (เช่น ระบบ Wi-FiหรือBluetooth ) คอมพิวเตอร์สมัยใหม่ทุกเครื่องสามารถรองรับการเชื่อมต่อทั้งสองแบบนี้ได้

เครือข่ายแบบนี้ไม่ได้จำกัดแค่สองเครื่อง คุณสามารถเชื่อมต่อคอมพิวเตอร์ได้มากเท่าที่คุณต้องการ แต่ก็จะยุ่งยากขึ้นอย่างรวดเร็ว ถ้าคุณพยายามเชื่อมต่อคอมพิวเตอร์สิบเครื่อง 
คุณจะต้องใช้สายเคเบิลถึง 45 เส้น โดยแต่ละเครื่องมีปลั๊กถึงเก้าตัว!

เพื่อแก้ปัญหานี้ คอมพิวเตอร์แต่ละเครื่องในเครือข่ายจะเชื่อมต่อกับคอมพิวเตอร์ขนาดเล็กพิเศษที่เรียกว่าสวิตช์เครือข่าย (หรือ เรียกสั้น ๆ ว่า สวิตช์ ) 
สวิตช์นี้มีหน้าที่เพียงอย่างเดียว คือ ทำหน้าที่เหมือนผู้ส่งสัญญาณที่สถานีรถไฟ คอยตรวจสอบให้แน่ใจว่าข้อความที่ส่งจากคอมพิวเตอร์เครื่องหนึ่งไปถึงคอมพิวเตอร์ปลายทางที่ต้องการเท่านั้น 
ในการส่งข้อความไปยังคอมพิวเตอร์ B คอมพิวเตอร์ A จะส่งข้อความไปยังสวิตช์ ซึ่งสวิตช์จะส่งต่อข้อความไปยังคอมพิวเตอร์ B อีกที คอมพิวเตอร์ B 
จะไม่ได้รับข้อความที่ส่งไปยังคอมพิวเตอร์เครื่องอื่น และข้อความใด ๆ ที่ส่งไปยังคอมพิวเตอร์ B ก็จะไม่ถึงคอมพิวเตอร์เครื่องอื่น ๆ ในเครือข่ายท้องถิ่นด้วย

เมื่อเราเพิ่มสวิตช์เข้าไปในระบบแล้ว เครือข่ายคอมพิวเตอร์ 10 เครื่องของเราก็จะต้องการเพียง 10 สายเคเบิลเท่านั้น: ปลั๊กเดี่ยวสำหรับแต่ละเครื่อง และสวิตช์ที่มีปลั๊ก 10 ช่อง

เครือข่ายของเครือข่าย
ทุกอย่างดูดีจนถึงตอนนี้ แต่ถ้าเราเชื่อมต่อคอมพิวเตอร์หลายร้อย หลายพัน หรือหลายพันล้านเครื่องล่ะ? แน่นอนว่าสวิตช์ตัวเดียวไม่สามารถรองรับการขยายตัวได้มากขนาดนั้น 
แต่ถ้าคุณอ่านอย่างละเอียด
 เราจะเห็นว่าเราบอกว่าสวิตช์ก็เป็นคอมพิวเตอร์เหมือนกับคอมพิวเตอร์อื่นๆ ดังนั้นอะไรที่ทำให้เราไม่สามารถเชื่อมต่อสวิตช์สองตัวเข้าด้วยกันได้? ไม่มีอะไรเลย
 คุณอาจนึกภาพออกว่าเราสามารถเชื่อมต่อสวิตช์เข้าด้วยกันได้เรื่อยๆ อย่างไม่มีที่สิ้นสุด

 ในความเป็นจริงแล้ว สิ่งนี้ทำให้เกิดปัญหาทางวิศวกรรมมากมาย ยิ่งแพ็กเก็ตต้องผ่านสวิตช์มากเท่าไหร่ ก็ยิ่งใช้เวลานานขึ้นในการไปถึงปลายทาง 
 และคุณไม่สามารถใช้สวิตช์แบบเรียงเป็นต้นไม้ได้ เพราะหากสวิตช์ตัวใดตัวหนึ่งเสีย อาจทำให้การเชื่อมต่อของอุปกรณ์จำนวนมากขาดหายไป 
 เพื่อแก้ปัญหานี้ เราจึงทำให้เครือข่ายท้องถิ่นแต่ละเครือข่ายมีขนาดเล็กที่สุดเท่าที่จะเป็นไปได้ 
 และเชื่อมต่อเครือข่ายท้องถิ่นเหล่านี้โดยใช้อุปกรณ์แยกต่างหากที่เรียกว่าเราเตอร์เราเตอร์คือคอมพิวเตอร์ที่รู้วิธีการส่งต่อข้อความระหว่างเครือข่าย เราเตอร์เปรียบเสมือนที่ทำการไปรษณีย์ 
 เมื่อแพ็กเก็ตมาถึง มันจะอ่านที่อยู่ผู้รับและส่งต่อแพ็กเก็ตไปยังผู้รับที่ถูกต้องโดยตรง โดยไม่ต้องผ่านรีเลย์หลายชั้น

 เครือข่ายดังกล่าวมีความคล้ายคลึงกับสิ่งที่เราเรียกว่าอินเทอร์เน็ตมาก เราเพียงแค่ต้องการสื่อทางกายภาพ (สายเคเบิล) เพื่อเชื่อมต่อเราเตอร์ทั้งหมดเหล่านี้ 
 โชคดีที่โครงสร้างพื้นฐานดังกล่าวมีอยู่แล้วก่อนอินเทอร์เน็ต และนั่นก็คือเครือข่ายโทรศัพท์ ในการเชื่อมต่อเครือข่ายของเรากับโครงสร้างพื้นฐานโทรศัพท์ 
 เราจำเป็นต้องใช้อุปกรณ์พิเศษที่เรียกว่าโมเด็มโมเด็มนี้จะแปลงข้อมูลจากเครือข่ายของเราให้เป็นข้อมูลที่โครงสร้างพื้นฐานโทรศัพท์สามารถจัดการได้ และในทางกลับกัน
 โปรดทราบว่าเราเตอร์เชิงพาณิชย์ในบ้านของคุณนั้นมักจะเป็นอุปกรณ์ที่รวมเอาฟังก์ชันต่างๆ ไว้ในตัวเดียว เช่น สวิตช์ เราเตอร์ และโมเด็ม

ดังนั้นเราจึงเชื่อมต่อกับโครงสร้างพื้นฐานของโทรศัพท์แล้ว ขั้นตอนต่อไปคือการส่งข้อความจากเครือข่ายของเราไปยังเครือข่ายที่เราต้องการเข้าถึง
 เพื่อให้บรรลุเป้าหมายนั้น เราจะเชื่อมต่อเครือข่ายของเรากับผู้ให้บริการอินเทอร์เน็ต (ISP) ISP คือบริษัทที่จัดการเราเตอร์ พิเศษบางตัว ที่เชื่อมโยงกันทั้งหมด 
 และยังสามารถเข้าถึงเราเตอร์ของ ISP อื่นๆ ได้อีกด้วย 
ดังนั้นข้อความจากเครือข่ายของเราจึงถูกส่งผ่านเครือข่ายของเครือข่าย ISP ไปยังเครือข่ายปลายทาง อินเทอร์เน็ตประกอบด้วยโครงสร้างพื้นฐานของเครือข่ายทั้งหมดนี้

การค้นหาคอมพิวเตอร์
หากคุณต้องการส่งข้อความไปยังคอมพิวเตอร์ คุณต้องระบุว่าต้องการส่งข้อความไปยังเครื่องใด ดังนั้นคอมพิวเตอร์ทุกเครื่องที่เชื่อมต่อกับเครือข่ายจะมีที่อยู่เฉพาะที่ใช้ระบุตัวตน 
เรียกว่า "ที่อยู่ IP" (โดยที่ IP ย่อมาจากInternet Protocol ) ที่อยู่ดังกล่าวประกอบด้วยตัวเลขสี่หลักคั่นด้วยจุด ตัวอย่างเช่น: 192.0.2.172.

นั่นใช้ได้ดีกับคอมพิวเตอร์ แต่พวกเรามนุษย์จำที่อยู่แบบนั้นได้ยาก เพื่อให้ง่ายขึ้น เราสามารถตั้งชื่อเล่นให้กับที่อยู่ IP ด้วยชื่อที่มนุษย์อ่านได้ เรียกว่าชื่อโดเมนตัวอย่างเช่น
 (ณ เวลาที่เขียนบทความนี้ ที่อยู่ IP อาจเปลี่ยนแปลงได้) 
google.comคือชื่อโดเมนที่ใช้ต่อท้ายที่อยู่ IP 142.250.190.78ดังนั้นการใช้ชื่อโดเมนจึงเป็นวิธีที่ง่ายที่สุดในการเข้าถึงคอมพิวเตอร์ผ่านทางอินเทอร์เน็ต

อินเทอร์เน็ตและเว็บ
อย่างที่คุณอาจสังเกตเห็น เมื่อเราท่องเว็บด้วยเว็บเบราว์เซอร์ เรามักใช้ชื่อโดเมนเพื่อเข้าถึงเว็บไซต์ นั่นหมายความว่าอินเทอร์เน็ตและเว็บเป็นสิ่งเดียวกันหรือไม่? 
มันไม่ง่ายอย่างนั้น อย่างที่เราเห็น อินเทอร์เน็ตเป็นโครงสร้างพื้นฐานทางเทคนิคที่ช่วยให้คอมพิวเตอร์หลายพันล้านเครื่องเชื่อมต่อกันได้ ในบรรดาคอมพิวเตอร์เหล่านั้น
 มีคอมพิวเตอร์บางเครื่อง (เรียกว่าเว็บเซิร์ฟเวอร์ ) ที่สามารถส่งข้อความที่เว็บเบราว์เซอร์เข้าใจได้อินเทอร์เน็ตเป็นโครงสร้างพื้นฐาน ในขณะที่เว็บ เป็นบริการที่สร้างขึ้นบนโครงสร้างพื้นฐาน 
 นั้นเป็นที่น่าสังเกตว่ายังมีบริการอื่นๆ อีกหลายอย่างที่สร้างขึ้นบนอินเทอร์เน็ต เช่น อีเมลและIRC

อินทราเน็ตและเอ็กซ์ทราเน็ต
อินทราเน็ตเป็น เครือข่าย ส่วนตัวที่จำกัดเฉพาะสมาชิกขององค์กรนั้นๆ โดยทั่วไปแล้วจะใช้เป็นช่องทางให้สมาชิกเข้าถึงทรัพยากรที่ใช้ร่วมกันได้อย่างปลอดภัย 
ทำงานร่วมกัน และสื่อสารกัน ตัวอย่างเช่น อินทราเน็ตขององค์กรอาจมีเว็บเพจสำหรับแบ่งปันข้อมูลของแผนกหรือทีม ไดรฟ์ที่ใช้ร่วมกันสำหรับการจัดการเอกสารและไฟล์สำคัญ 
พอร์ทัลสำหรับการดำเนินงานด้านบริหารธุรกิจ และเครื่องมือสำหรับการทำงานร่วมกัน เช่น วิกิ กระดานสนทนา และระบบส่งข้อความ

เอ็กซ์ทราเน็ตมีความคล้ายคลึงกับอินทราเน็ตมาก แต่แตกต่างตรงที่เปิดเครือข่ายส่วนตัวทั้งหมดหรือบางส่วนเพื่อให้สามารถแบ่งปันและทำงานร่วมกันกับองค์กรอื่นได้ 
โดยทั่วไปแล้วจะใช้เพื่อแบ่งปันข้อมูลอย่างปลอดภัยกับลูกค้าและผู้มีส่วนได้ส่วนเสียที่ทำงานร่วมกับธุรกิจอย่างใกล้ชิด ฟังก์ชันการทำงานของเอ็กซ์ทราเน็ตมักจะคล้ายกับที่อินทราเน็ตมีให้ 
เช่น การแบ่งปันข้อมูลและไฟล์ เครื่องมือการทำงานร่วมกัน กระดานสนทนา เป็นต้น

ทั้งอินทราเน็ตและเอ็กซ์ทราเน็ตทำงานบนโครงสร้างพื้นฐานแบบเดียวกับอินเทอร์เน็ต และใช้โปรโตคอลเดียวกัน ดังนั้น สมาชิกที่ได้รับอนุญาตจึงสามารถเข้าถึงได้จากสถานที่ต่างๆ กัน
