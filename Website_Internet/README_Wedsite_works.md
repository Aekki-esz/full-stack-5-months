เมื่อเราเปิดเว็บไซต์ เกิดอะไรขึ้น?

เริ่มต้น
ผู้ใช้เปิด Browser และพิมพ์ URL ของเว็บไซต์ URL ทำหน้าที่บอกตำแหน่งของข้อมูลที่เราต้องการเข้าถึง

DNS
Browser นำชื่อ Domain ไปสอบถาม DNS เพื่อค้นหา IP Address ของ Server เพราะคอมพิวเตอร์ใช้หมายเลข IP ในการระบุเครื่องปลายทาง

Request และ Response
เมื่อทราบ IP แล้ว Browser ซึ่งทำหน้าที่เป็น Client จะเชื่อมต่อกับ Server และส่ง HTTP Request เช่น GET 
เพื่อขอหน้าเว็บไซต์ จากนั้น Server 
ประมวลผลและส่ง HTTP Response กลับมา

การแสดงผล
Browser อ่าน HTML เพื่อสร้างโครงสร้างหน้าเว็บ อ่าน CSS เพื่อจัดรูปแบบ และประมวลผล JavaScript 
เพื่อเพิ่มการทำงานหรือการโต้ตอบ 
รวมทั้งดาวน์โหลดรูปภาพและไฟล์อื่น ๆ ก่อนแสดงผลบนหน้าจอ

URL บอกว่าจะไปที่ไหน
DNS ช่วยหา IP ของ Server
HTTP เป็นกติกาการรับส่งข้อมูล
Client เป็นฝ่ายส่งคำขอ
Server เป็นฝ่ายประมวลผลและตอบกลับ
Browser นำข้อมูลที่ได้รับมาประกอบและแสดงเป็นหน้าเว็บไซต์
